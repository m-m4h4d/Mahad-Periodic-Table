MTH Periodic Table (desktop) - version {version}
================================================

Track every element of the periodic table, browse pictures of the elements,
look up their properties, test yourself with the quiz and add your own notes.

Requirements
  Python 3.6 or newer with Tkinter (included with the python.org installers).
  Get Python from https://www.python.org/downloads/

Start the app
  Windows : double-click "Start Periodic Table (Windows).bat"
  macOS   : double-click "Start Periodic Table (macOS).command"
            (first time: right-click > Open, then confirm)
  Linux   : run ./start-linux.sh
  Any OS  : python3 launcher.py

Log in with an account from app/students_account.txt or create a new one on
the start screen (the CMS ID must be 11 digits). Accounts and the notes you
add under "Play your part" are saved in the text files inside app/.

Prefer not to install anything? Use the browser version:

Desktop version of the MTH Periodic Table (Python + Tkinter).

**Download `Mahad-Periodic-Table-desktop.zip`**, extract it, then:

- **Windows:** double-click `Start Periodic Table (Windows).bat`
- **macOS:** double-click `Start Periodic Table (macOS).command` (first time: right-click → Open)
- **Linux:** run `./start-linux.sh`

Requires Python 3.6+ with Tkinter, which the installers from [python.org](https://www.python.org/downloads/) include.
